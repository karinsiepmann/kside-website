Die Herausforderung

Such dir einen KI-Chatbot oder eine Anwendung deiner Wahl und formuliere die Erstellung einer interaktiven Seite oder eines Dashboards zu einem Thema deiner Wahl.

1. Thema wählen

Was beschäftigt dich gerade? Reisekosten, Trainingspläne, Projektdaten - dein Thema, deine Seite.

2. Chatbot ansprechen

Schreibe oder sprich in eigenen Worten, was die Seite können soll. Iteriere, frag nach, verfeinere.

3. Ausprobieren

Öffne die Seite, teste sie, zeig sie herum. Fehler sind Zwischenschritte, kein Ende.

Beispiele - so kann das aussehen


Beispiel 1

Erasmus-Reisekostenrechner

Ein interaktiver Rechner, der Pauschalen und Reisekosten für Erasmus+-Projekte direkt im Browser zusammenrechnet - gebaut im Dialog mit einem KI-Chatbot.

Beispiel 2

Vom PDF zur interaktiven Seite

Aus einem statischen PDF wird eine interaktive Webseite: derselbe Inhalt, aber klickbar, durchsuchbar und lebendig - ein Beispiel dafür, wie viel in vorhandenen Materialien steckt.

Zur interaktiven Seite
Ergänze jeden Prompt mit dem Zusatz »und mach mir daraus eine interaktive HTML-Seite« - schon wird aus einer Antwort etwas Klickbares. (frei nach Jens Polomski)
